# פרד"ס חקירות – אתר

עיצוב חדש לאתר https://prdsbi.com/ עם אותו תוכן. אתר סטטי בקובץ יחיד (`index.html`), עם ניווט בין עמודים לפי hash:
`#about`, `#services`, `#cases`, `#contact`, `#privacy`, `#terms`, `#accessibility`.

## מבנה

- `src/template.html` – המקור לעריכה (HTML, CSS ו-JS). התמונות מסומנות כ-`{{IMG:name}}`.
- `src/images/` – הלוגו והתמונות (webp) שהועתקו מהאתר המקורי.
- `build.js` – בונה את `index.html` ומטמיע את התמונות כ-data URI.
- `index.html` – הקובץ המוכן להעלאה.

## בנייה מחדש

```
node build.js
```

## הערות

- הטופס עדיין לא שולח הודעות: הוא מכין הודעה ופותח מייל אל info@prdsbi.com. לפני עלייה לאוויר צריך לחבר אותו לשרת שמקבל פניות.
- בעמודי הפרטיות והתנאים של האתר המקורי הייתה שורת כתובת עם placeholder (`[business_address]`). היא הושמטה, וצריך להוסיף כתובת אמיתית.
- שעות הפעילות באתר המקורי לא אחידות (24 שעות בפוטר, 09:00–17:00 בעמוד צור קשר). הועתקו כמו שהן.
