# פרד"ס חקירות – אתר

עיצוב חדש לאתר https://prdsbi.com/ עם אותו תוכן, בשתי שפות:

- `index.html` – עברית (השפה הראשית, מימין לשמאל), בכתובת `/`
- `en/index.html` – אנגלית (משמאל לימין), בכתובת `/en/`

כל שפה היא קובץ אחד, עם ניווט בין עמודים לפי hash:
`#about`, `#services`, `#cases`, `#contact`, `#privacy`, `#terms`, `#accessibility`.
כפתור השפה בכותרת ובפוטר פותח את אותו עמוד בשפה השנייה. לכל שפה יש `lang`/`dir`, כותרת ותיאור משלה, `canonical`, ותגיות `hreflang` (he, en, x-default=he) לגוגל.

## מבנה

- `src/body.he.html`, `src/body.en.html` – תוכן העמודים בכל שפה. כשמשנים טקסט, צריך לשנות בשני הקבצים. התמונות מסומנות כ-`{{IMG:name}}`.
- `src/style.css` – העיצוב המשותף. משתמש במאפיינים לוגיים (`inline-start`/`inline-end`), כך שהוא עובד גם מימין לשמאל וגם משמאל לימין.
- `src/script.js` – ניווט, כותרות העמודים, כפתור השפה והטופס (עם טקסטים בשתי השפות).
- `src/images/` – הלוגו והתמונות (webp) שהועתקו מהאתר המקורי.
- `build.js` – בונה את `index.html` ואת `en/index.html`, עם תגיות ה-SEO לכל שפה, ומטמיע את התמונות כ-data URI.
- `index.html`, `en/index.html` – הקבצים המוכנים להעלאה.

## בנייה מחדש

```
node build.js
```

## הערות

- הטפסים שולחים את הפניות ל-info@prdsbi.com דרך השירות FormSubmit (formsubmit.co). בפנייה הראשונה FormSubmit שולח לכתובת הזו מייל אישור, וצריך ללחוץ על הקישור שבו. רק אחרי זה הפניות יגיעו.
- בעמודי הפרטיות והתנאים של האתר המקורי הייתה שורת כתובת עם placeholder (`[business_address]`). היא הושמטה, וצריך להוסיף כתובת אמיתית.
- שעות הפעילות באתר המקורי לא אחידות (24 שעות בפוטר, 09:00–17:00 בעמוד צור קשר). הועתקו כמו שהן.
- עמודי הפרטיות והתנאים באנגלית הם תרגום, ומציינים שהגרסה העברית היא המחייבת.
